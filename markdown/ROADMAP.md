# SafePoint Roadmap

## Current Goal

Prepare SafePoint for a hackathon demo focused on worker-side safety comprehension and strong Agnes AI API usage.

## Milestone 1: Core Scan Demo

- [ ] Camera/image upload
- [ ] Language selector
- [ ] Backend scan endpoint
- [ ] Agnes vision integration or mock wrapper
- [ ] OCR/detected text output
- [ ] Risk card display
- [ ] Action steps display

## Milestone 2: Multimodal Output

- [ ] Native-language explanation
- [ ] Audio guidance
- [ ] Pictogram prompt
- [ ] Generated pictogram card
- [ ] Sample fallback mode

## Milestone 3: Incident Reporting

- [ ] Worker-language incident input
- [ ] English report draft
- [ ] Incident category
- [ ] Suggested next step
- [ ] Confirmation before saving/sharing

## Milestone 4: Demo Polish

- [ ] 3 sample images
- [ ] Smooth demo script
- [ ] Fallback sample responses
- [ ] Clean UI
- [ ] Pitch-safe claims
- [ ] No secrets committed

## Milestone 5: Stretch

- [ ] Daily briefing generator
- [ ] 30-second video briefing prompt/output
- [ ] Saved cards
- [ ] Anonymous scan trend analytics
- [ ] Supervisor briefing creation flow

## Priority Rules

1. Main scan flow before dashboards.
2. Worker comprehension before management analytics.
3. Reliability before polish.
4. Safety wording before aggressive claims.
5. Privacy before storage.
