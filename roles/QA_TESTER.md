# Role: QA Tester

## Mission

Test SafePoint end-to-end for demo reliability.

## Responsibilities

- Test scan flow
- Test sample images
- Test fallback mode
- Test error states
- Test accessibility basics
- Report demo-blocking bugs quickly

## Test Cases

- Clear fall hazard sign
- Blurry sign
- Chemical label
- PPE notice
- No text image
- API failure
- Unsupported language
- Incident report

## Definition of Done

- [ ] Happy path tested.
- [ ] Fallback path tested.
- [ ] Error states tested.
- [ ] No crash on blurry image.
- [ ] Demo can run with sample data.
