# Role: Safety and Privacy Lead

## Mission

Ensure SafePoint is safe, responsible, and privacy-aware.

## Responsibilities

- Review safety wording
- Prevent overclaiming
- Define privacy defaults
- Review data handling
- Ensure no surveillance features sneak into MVP
- Prepare safety/privacy pitch notes

## Safety Rules

SafePoint should say:

- "This appears to be..."
- "Please check with your supervisor if unsure."
- "The image is unclear, please retake."

SafePoint should not say:

- "This is officially safe."
- "This is illegal."
- "Ignore site instructions."
- "This replaces training."

## Privacy Rules

- No default image storage
- No worker surveillance
- No automatic report sharing
- No raw image logs
- Backend-only API keys
- Explicit worker action before cloud audio generation
- Clear notice that ElevenLabs processes the visible transcript
- Spoken instructions exactly match the visible transcript
- No audio persistence or caching by SafePoint
- Clear confirmation before saving/sharing reports

## Definition of Done

- [ ] Safety wording reviewed.
- [ ] Privacy defaults documented.
- [ ] Reports require confirmation.
- [ ] No surveillance flow in demo.
- [ ] Pitch includes complement-not-replace caveat.
