# Role: UX/UI Designer

## Mission

Design a simple, worker-friendly, camera-first safety interface.

## Responsibilities

- Design main user flow
- Create wireframes and high-fidelity mockups
- Design risk cards
- Design pictogram card layout
- Design audio guidance controls
- Design incident report flow
- Ensure low-literacy and multilingual usability

## Key Screens

- Home screen
- Camera scan screen
- Scan progress screen
- Risk result screen
- Pictogram card screen
- Incident report screen
- Daily briefing screen

## Design Principles

- One main action per screen
- Large buttons
- Clear icons
- High contrast risk levels
- Minimal text
- Native-language support
- Audio-first guidance
- No dashboard clutter

## Risk Card Layout

Recommended order:

1. Risk level
2. Main warning
3. What to do now
4. PPE required
5. Audio button
6. Pictogram card
7. Retake / Save / Report

## Deliverables

- User flow
- Wireframes
- Risk card design
- Pictogram card design
- Demo screen sequence
- Design system notes
